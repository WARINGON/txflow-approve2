Approve a TxFlow trading agent

TxFlow requires two owner-wallet signatures, in this order: approve a builder cap, then approve the agent. The official app does not show an API-wallet screen, so this page does both.

The official TxFlow app does not use a builder (your app trades already work without one). The public API still requires at least one builder approval before it will accept an agent. The cap below is the minimum allowed (0.001%). Approving a cap is not a charge. Bot orders will not attach this builder, so you should not pay an extra builder fee. This uses a new agent label, so it will not replace your TxFlow app key.

  1. Open this page in Rabby’s in-app / dApp browser (not the TxFlow app).
  2. Connect the same wallet you already use on TxFlow.
  3. If asked, switch to Arbitrum One.
  4. Tap the button. Rabby will ask you to sign twice: first ApproveBuilderFee, then ApproveAgent. No gas is needed.
